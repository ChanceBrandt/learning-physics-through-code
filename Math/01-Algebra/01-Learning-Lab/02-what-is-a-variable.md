## Quantities in an Equation 
- **Independent Variable:** The variable that is free to change
- **Dependent Variable:** The variable whose output depends on the value of the independent variable 
- **Constant:** A quantity whose value remains the same regardless of changes to the input or output 

**Example 1:** Going back to the Linear Form of an Equation y = mx + b
X is the INDEPENDENT variable as it freely changes 
Y is the DEPENDENT variable as its output depends on the changes of the x value 
M and B are constants as the slope (m) and y-intercept (b) of a LINEAR line does not change

**Example 2:** d = vt 
d is distance, v is velocity, t is time 
Suppose an object moves at a constant velocity of 5 m/s 
This would mean that
T is the INDEPENDENT variable as it freely changes 
D is the DEPENDENT variable as its output depends on changes in time 
V is a CONSTANT as its value does not change
