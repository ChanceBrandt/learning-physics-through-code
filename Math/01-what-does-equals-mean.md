# What Does the Equal Sign Actually Mean?

## What I think Right Now
The equal sign is a symbol that compares two values or equations stating that one MUST be the same as the other. 

## Updated Understanding
The equal sign is not really a comparison, it is a symbol to denote the statment that the value on the right equals the same value as what is on the left. 

It is important to recognize that it is the value itself, not the expressions, that must be equal.  There can be two different expressions that then equal the same value, which would be denoted by an equal sign 

Example: 3 + 4 = 5 + 2, which means 7 = 7, which is a valid statment. 

# Why am I allowed to perform the same operation on both sides of an equation? 

## What I think Right now
For balance. If I am revewing an equation with the goal of making both sides equal, what I do to one side I must do to the other.  Otherwise it intrinsically changes the starting values. 

## Updated Understanding 
What does "balance" mean mathematically? 

Simply, if I say 7 = 7
Then I only subtract 3 from the left side: 7 - 3 = 7 
This would mean 4 = 7, which is not true 

In order to satisfy the requirement that both sides are equal, I must perform the same operation on both sides. 

**EXAMPLE:**
Start with $x + 4 = 7$
Only subtract 4 from the left: x + 4 - 4 = 7
This would mean x = 7. 
If I plug that back into the starting equation then that would be 7 + 4 = 7 or 11  = 7, which is not a true statement. 

Now Start again with x + 4 = 7 
Subtract 4 from BOTH sides: x + 4 - 4 = 7 - 4
This would mean x = 3
Plugging that back into the starting equation, 3 + 4 = 7 or 7 = 7, which is a true statement. 

**IMPORTANT NOTE:** When solving an equation, my goal is not to "make" the two sides equal.  The equals sign alread ASSERTS that they MUST be.  My goal is to perform mathematical operations that preserve that equality in order to describe the relationship between quantities.
